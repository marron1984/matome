# まとめのまとめ

複数の「まとめサイト」のRSSを1か所に集めて、**新着順／人気順**で読むためのアグリゲーターです。
スマホでの片手読みを想定した5タブ構成（最新／記事を探す／ブックマーク／ブログ／設定）で、
Node.js標準機能だけで動きます（**依存パッケージゼロ**、ビルド不要）。

```
┌──────────┐   RSS/RDF/Atom   ┌─────────┐   はてブ数   ┌──────────┐
│ まとめブログ  │ ───────────────▶ │ crawler │ ──────────▶ │  store   │
└──────────┘                   └─────────┘             │ (JSON 1枚) │
                                                        └────┬─────┘
                                     /api/articles           │
                              ┌────────────────────────┐     │
                              │  server (node:http)     │◀────┘
                              └───────────┬────────────┘
                                          │  fetch
                              ┌───────────▼────────────┐
                              │ public/ (素のJS SPA)     │
                              └────────────────────────┘
```

## 使い方

```bash
node src/cli.js seed     # サンプル記事を投入（ネットワーク不要。まず動かしたいとき）
node src/cli.js crawl    # 実際のまとめブログからRSSを取得（要ネットワーク）
node src/cli.js serve    # http://localhost:3000 で起動（10分ごとに自動クロール）
npm test                 # テスト（49件）
```

`npm start` / `npm run crawl` / `npm run seed` も同じです。

### コマンド

| コマンド | 説明 |
| --- | --- |
| `serve [--port 3000] [--interval 10]` | サーバ起動。`--interval` は自動クロールの分間隔（`0` で無効） |
| `crawl [--no-bookmarks]` | フィードを1回取得してストアを更新 |
| `seed` | `fixtures/` のサンプル記事を投入（オフライン確認用） |
| `sources` | 購読ブログ一覧と最終取得状況を表示 |

### 環境変数

| 変数 | 既定値 | 説明 |
| --- | --- | --- |
| `PORT` | `3000` | `serve` のポート |
| `MATOME_DATA_DIR` | `./data` | 記事データの保存先 |
| `MATOME_SOURCES` | `./config/sources.json` | 購読ブログ定義 |
| `MATOME_CRAWL_INTERVAL` | `10` | 自動クロールの分間隔 |

## 購読ブログの追加・削除

`config/sources.json` を編集するだけです。RSS 2.0 / RSS 1.0(RDF) / Atom のいずれにも対応しています。

```json
{ "id": "myblog", "name": "マイまとめ", "category": "総合",
  "site": "https://example.com/", "feed": "https://example.com/index.rdf",
  "weight": 1, "enabled": true }
```

- `id`: 内部の一意キー（記事の紐付けに使うので後から変えない）
- `weight`: 人気スコアの補正係数。`0.5` で目立ちにくく、`1.5` で目立ちやすくなります
- `enabled: false`: 定義を残したままクロール対象から外します

取得に失敗したブログは他のブログに影響させず、理由をストアに記録して「ブログ」タブに表示します。

## ランキングの考え方

- **新着**: 記事の公開時刻の降順。
- **人気**: はてなブックマーク数を対数で効かせ、経過時間で減衰させたスコア順（既定は直近48時間）。

```
score = (log(1 + はてブ数) * 10 + 1) / (1 + 経過時間/8h)^1.4 * ブログのweight
```

はてブ数は直近48時間の記事だけ、まとめて（1リクエスト50URL）取得します。
取得できない環境ではスコアが時間減衰のみになり、実質「新着順」に縮退します。

## 画面

| タブ | 内容 |
| --- | --- |
| 最新 | 新着／人気の切り替え、無限読み込み、既読はグレー表示 |
| 記事を探す | キーワード検索（スペース区切りAND、全角/半角・大文字小文字を吸収）とブログ絞り込み |
| ブックマーク | ☆で保存した記事の一覧 |
| ブログ | 購読ブログの一覧・記事数・取得エラー、スイッチで非表示、名前タップでそのブログだけ表示 |
| 設定 | 既読を隠す／サムネイル／テーマ／文字サイズ／人気の集計期間／読み込み件数／NGワード |

既読・ブックマーク・設定はブラウザの `localStorage` にのみ保存され、サーバには送りません。

## 構成

```
config/sources.json   購読ブログ定義
src/xml.js            軽量XMLヘルパー（実体参照・CDATA・属性）
src/feed.js           RSS2.0 / RDF / Atom → 共通フォーマット
src/url.js            URL正規化（トラッキングパラメータ除去など）
src/http.js           fetchラッパ（タイムアウト・リトライ・文字コード判定）
src/hatena.js         はてなブックマーク数の一括取得
src/store.js          JSON1枚の記事ストア（重複排除・保持期間の管理）
src/rank.js           並べ替え・絞り込み・NGワード
src/crawler.js        クロールの全体制御
src/server.js         静的配信 + JSON API
src/seed.js           サンプル記事の投入
src/cli.js            CLIエントリポイント
public/               フロントエンド（素のHTML/CSS/JS）
fixtures/             オフライン確認・テスト用のサンプルフィード
test/                 node:test によるテスト
```

## API

| エンドポイント | 説明 |
| --- | --- |
| `GET /api/articles?tab=latest\|popular&q=&sources=&ng=&hours=&limit=&offset=` | 記事一覧 |
| `GET /api/sources` | 購読ブログ一覧（記事数・最終取得状況つき） |
| `GET /api/status` | 記事数・最終更新時刻 |
| `POST /api/refresh` | 手動クロール（同時実行は1本にまとめられます） |

## 運用メモ

- 記事は既定で14日・5000件を上限に保持し、超過分は古い順に捨てます（`src/store.js`）。
- ストアは一時ファイル経由で書き込むため、途中終了してもJSONが壊れません。
- クロールは同時4本、フィード1本あたり最新30件まで取り込みます。
- 配信元サイトへの負荷を考え、`--interval` を極端に短くしないでください（既定10分）。
- 記事本文は保存せず、タイトル・リンク・要約（先頭140文字）・サムネイルURLのみを扱います。
  一覧から元記事へリンクする形なので、閲覧は各まとめサイト上で行われます。
